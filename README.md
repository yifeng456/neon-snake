# 霓虹贪吃蛇（Neon Snake）

一款纯前端实现的霓虹风格贪吃蛇小游戏，无需任何构建工具或依赖，打开即玩。

## 在线试玩

👉 <https://yifeng456.github.io/neon-snake/>

## 玩法说明

- 控制贪吃蛇吃掉发光的食物，每吃一个 +10 分
- 每吃满 3 个食物升 1 级，速度加快，并出现新的障碍物
- 食物会周期性移动，且倾向于远离蛇头；蛇越长，食物移动越快（但始终慢于蛇）
- 每吃掉一个食物，食物会变换一种颜色
- 蛇身初始为红黄蓝绿淡色，吃食后新增的蛇身段会染上对应食物的淡色
- 第 3 关起会出现「?」白色发光道具（每关一次），拾取后随机获得：隐身 30 秒（可穿障碍、穿墙）或 10 颗子弹（射击击碎障碍，击碎永久生效）
- 撞墙、撞障碍、撞到自己都会结束游戏
- 最高分会保存在本地浏览器中

## 操作方式

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 方向 | 方向键 / WASD | 滑动 |
| 射击（有子弹时） | 空格 | 点击屏幕 |
| 暂停 / 继续 | P / Esc | — |
| 静音 | M | — |
| 开始 / 再来一局 | Enter | 点击按钮 |

## 技术栈

- 原生 HTML / CSS / JavaScript（无构建、无框架、无依赖）
- Canvas 2D 渲染
- Web Audio API 合成音效与背景音乐
- 响应式布局，适配移动端

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动任意静态服务器：

```bash
# 例如使用 Python
python -m http.server 8000
```

然后访问 <http://localhost:8000>。
