# 霓虹贪吃蛇（Neon Snake）

一款纯前端实现的霓虹风格贪吃蛇小游戏，无需任何构建工具或依赖，打开即玩。

## 在线试玩

👉 <https://yifeng456.github.io/neon-snake/>

## 玩法说明

- 控制贪吃蛇吃掉发光的食物，每吃一个 +10 分
- **升级**：每吃满 3 个食物升 1 级，蛇移动速度加快（150ms 起，每级 -10ms，下限 80ms）
- **障碍随机**：障碍物随机位置生成（每次游玩都不同）、均匀分布、不贴墙，每级新增约 5 个（封顶 40 个）
- **食物移动**：食物会周期性移动，且倾向于远离蛇头；蛇越长，食物移动越快（但始终慢于蛇）

| 蛇身长度 | 食物移动间隔 | 相对蛇的速度 |
| --- | --- | --- |
| 4–6 | 每 5 步 | 1/5 倍 |
| 7–9 | 每 4 步 | 1/4 倍 |
| 10–12 | 每 3 步 | 1/3 倍 |
| 13+ | 每 2 步 | 1/2 倍（上限） |

- **变色与成长**：每吃掉一个食物，食物会变换一种颜色；蛇身初始为红黄蓝绿淡色，吃食后新增的蛇身段会染上对应食物的淡色
- 撞墙、撞障碍、撞到自己都会结束游戏
- 最高分会保存在本地浏览器中

## 道具系统

道具每 30 秒出现一次——白色发光方块（中间有「?」），也会像食物一样移动（速度锁定为关卡一速度）。拾取后随机获得以下三种效果之一：

| 效果 | 说明 |
| --- | --- |
| 🫥 隐身 30 秒 | 蛇身半透明、无碰撞体积；可穿过障碍物和自己身体；撞墙时从相反方向出现 |
| 🔫 10 颗子弹 | 射击击碎障碍物（墙不可击碎），也可射击食物使其冻结 1 秒；空射也消耗子弹，击碎永久生效 |
| ❄️ 冻结 10 秒 | 食物停止移动，蛇仍可移动，10 秒后食物恢复移动 |

## 视觉与动画

- **霓虹画风**：渐变光晕、呼吸灯效、粒子星尘、食物旋转光环、地图外极光模糊背景（高斯模糊虚化）
- **蛇身**：红黄蓝绿淡色霓虹灯管渐变 + 顶部高光，蛇头带眼睛
- **平滑移动**：蛇与食物均采用渲染插值，从「跳格子」升级为丝滑连续滑动
- **吃食反馈**：张嘴（约 0.5 秒）→ 蛇头吞咽膨大回弹 → 金色粒子火花 → 扩散光环 → 中心爆闪 → 音效
- **射击特效**：青色光束 + 击碎爆裂粒子 + 爆闪

## 技术栈

- 原生 HTML / CSS / JavaScript（无构建、无框架、无依赖）
- Canvas 2D 渲染
- Web Audio API 合成音效与背景音乐
- 响应式布局，适配移动端

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动任意静态服务器：

```bash
# 例如使用 Python
python -m http.server 8000
```

然后访问 <http://localhost:8000>。
